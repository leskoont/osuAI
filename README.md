# OsuAI - Самообучающаяся нейронная сеть для игры в Osu!

## Описание
OsuAI - это проект самообучающейся нейронной сети, которая способна играть в ритм-игру Osu! Система анализирует экран, обнаруживает круги для нажатия и производит соответствующие действия мышью и клавиатурой.

## Функциональность
- Захват экрана и обработка изображения для нейронной сети
- Управление мышью и клавиатурой для игры
- Система обнаружения кругов и определения момента нажатия
- Система вознаграждений для обучения с подкреплением
- Сохранение и загрузка обученных моделей
- Визуализация прогресса обучения

## Требования
- Python 3.8+
- Установленная игра Osu!
- Зависимости из файла requirements.txt

## Установка
1. Клонируйте репозиторий:
```
git clone https://github.com/yourusername/OsuAI.git
cd OsuAI
```

2. Создайте виртуальное окружение и активируйте его:
```
python -m venv .venv
.venv\Scripts\activate
```

3. Установите зависимости:
```
pip install -r requirements.txt
```

## Использование
1. Запустите Osu! и перейдите к игровому экрану
2. Запустите нейронную сеть:
```
python main.py
```

3. Управление во время работы:
   - `p` - Пауза/Продолжение
   - `t` - Включение/Выключение обучения
   - `q` - Выход

## Структура проекта
- `main.py` - Основной файл для запуска программы
- `screen_capture.py` - Модуль захвата экрана
- `input_controller.py` - Модуль управления мышью и клавиатурой
- `neural_network.py` - Реализация нейронной сети
- `reward_system.py` - Система вознаграждений для обучения

## Настройка
Перед использованием рекомендуется настроить параметры под свой монитор:
1. Откройте `main.py` и измените переменные `screen_width` и `screen_height` на соответствующие размеры вашего экрана
2. При необходимости измените клавиши в `input_controller.py` для соответствия вашим настройкам управления в Osu!

## Примечания
- Для лучшей работы захвата экрана рекомендуется запускать Osu! в оконном режиме
- Производительность нейронной сети зависит от мощности вашего компьютера
- Для полного обучения модели может потребоваться значительное время
