# OsuAI — нейросеть, которая учится играть в osu!

Агент смотрит на игровое поле, двигает курсор и нажимает клавиши, а учится на
точных попаданиях 300/100/50/miss, которые [tosu](https://github.com/tosuapp/tosu) читает из памяти игры.

* **Алгоритм**: spatial Double-DQN (dueling, n-step) — сеть выдаёт Q-карту «куда поставить
  курсор × держать ли клавишу» — плюс DQfD-предобучение на записях вашей игры.
* **Скорость**: весь шаг агента (захват → сеть → ввод) укладывается в несколько миллисекунд на
  i5-10400 + RTX 2060. Обучение идёт в фоне и не мешает игре.
* **Симулятор**: встроенная мини-osu! для проверки, что обучение работает, без запуска игры.

Аудит исходной версии (28 найденных проблем), архитектура и оптимизации описаны в
[docs/PLAN.md](docs/PLAN.md).

## Установка (Windows, NVIDIA)

Нужен Python 3.10–3.12 (64-bit).

```bat
python -m venv .venv
.venv\Scripts\activate
pip install torch --index-url https://download.pytorch.org/whl/cu128
pip install -r requirements.txt
```

Для RTX 20xx (Turing, `sm_75`) подходят сборки PyTorch cu126/cu128. Команда
`python main.py benchmark` покажет видеокарту и предупредит, если в установленной сборке нет ядер для неё.

Для точных наград установите и запустите **tosu** (по умолчанию `ws://127.0.0.1:24050/ws`;
gosumemory тоже работает). Без tosu агент учится только на эвристике детектора кругов, и учится хуже.

### Настройка osu!
* Оконный или borderless режим (эксклюзивный полноэкранный режим может не захватываться).
* **Background dim 100%**, видео и сториборды выключены: агент видит только объекты.
* **Raw input выключен**: курсор ставится абсолютными координатами.
* Ограничьте FPS osu! (например, 240), чтобы оставить GPU для обучения.
* Клавиши Z/X, или укажите свои: `--keys a s`.

## Использование

```bat
python main.py benchmark                          :: замер скорости на вашем железе
python main.py train --sim                        :: проверка обучения в симуляторе
python main.py record --out demos\run1.npz        :: записать свою игру (демонстрации)
python main.py pretrain --demos "demos\*.npz"     :: предобучение на демонстрациях
python main.py train --demos "demos\*.npz"        :: онлайн-обучение в osu!
python main.py play                               :: игра обученной моделью (без обучения)
```

Горячие клавиши (во время `train`/`play`/`record`):

| Клавиша | Действие |
|---------|----------|
| `p` | пауза / старт (агент стартует на паузе) |
| `t` | обучение вкл/выкл |
| `s` | сохранить модель |
| `f` | переключить фокус на osu! |
| `q` | выход (с сохранением) |

Пока агент работает, он действует только когда окно osu! в фокусе и, при подключённом tosu,
только во время игры на карте (пауза в игре тоже распознаётся). Эпизод = одна попытка прохождения карты.

Окно **OsuAI Vision** показывает то, что видит сеть: кадр 96x128, тепловую карту Q-значений,
найденные круги (цвет = срочность) и курсор (красный, если клавиша зажата).

## Конфигурация

Все параметры собраны в `osuai/config.py`, пресет под i5-10400 + RTX 2060 лежит в
`configs/rtx2060.toml` и загружается по умолчанию. Любой параметр можно переопределить:

```bat
python main.py train --set train.batch_size=128 --set agent.hz=90
python main.py train --config my.toml
```

Самое важное:

| Параметр | По умолчанию | Смысл |
|----------|--------------|-------|
| `capture.region` | `playfield` | область захвата: `playfield`, `window`, `monitor`, `manual` |
| `capture.playfield_y_offset`, `margin_x/y` | 8 / 64 / 48 | подгонка области под playfield (osu!px) |
| `agent.hz` | 60 | частота решений агента |
| `agent.eps_decay_steps` | 150000 | сколько шагов длится исследование |
| `train.replay_ratio` | 0.5 | апдейтов сети на шаг игры |
| `train.replay_capacity` | 400000 | размер replay (~4.6 GB RAM) |
| `train.save_replay` | false | сохранять replay между запусками |
| `reward.*` | — | веса наград за 300/100/50/miss и эвристик |

Чекпоинт: `models/osuai.pt`, лог эпизодов: `logs/episodes.csv` (TensorBoard: `--set log.tensorboard=true`).
Модели старой версии (`.h5`, TensorFlow) несовместимы с новой архитектурой.

## Производительность (i5-10400 + RTX 2060)

| Стадия | Где выполняется | Время |
|--------|-----------------|-------|
| Захват playfield (dxcam) | поток capture | до 144+ FPS |
| Ресайз 1728x1296 → 128x96 | поток capture | ~0.4 мс |
| Детектор кругов | актор | ~0.2 мс |
| Инференс (fp16, CUDA Graph) | актор, high-priority stream | ~0.3–0.6 мс |
| Сборка батча | поток prefetch | ~0.6 мс |
| Апдейт сети, батч 64 | поток learner, low-priority stream | единицы мс |

Точные цифры для вашей машины покажет `python main.py benchmark`.

## Структура

```
main.py              CLI
configs/rtx2060.toml пресет под целевое железо
osuai/
  config.py          конфигурация (dataclass + TOML + --set)
  capture.py         поток захвата экрана (dxcam/mss) и предобработка
  env.py             среда «реальная osu!»: окно, область, ввод, tosu
  sim.py             симулятор osu! для отладки
  winapi.py          WinAPI на ctypes: DPI, окна, SendInput, таймер
  controller.py      ввод мыши/клавиш одним SendInput
  tosu.py            клиент tosu/gosumemory
  reward.py          детектор кругов, награды, привязка наград к нажатиям
  actions.py         пространство действий и геометрия playfield
  model.py           полностью свёрточная dueling Q-сеть
  agent.py           инференс актора (fp16, CUDA Graph), ε-greedy
  learner.py         Double-DQN + DQfD, AMP, фоновый поток и prefetch
  replay.py          replay-буфер uint8 с n-step и стеком кадров
  runner.py          главный цикл, режимы train/play/record/pretrain
  bench.py           бенчмарк
tests/               pytest: replay, награды, модель, сквозное обучение
```

Тесты: `pip install -r requirements-dev.txt && python -m pytest`.

## Примечания
* Используйте агента только офлайн или на приватных серверах: игра ботом на официальных серверах
  нарушает правила osu!.
* Для прочих режимов (taiko, catch, mania) нужны свои пространство действий и награды.
